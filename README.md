# Deccan Hi-Tech Constructions website

A responsive, multi-page static website based on the supplied Deccan Hi-Tech company profile and image assets.

## Pages

- `index.html` — Home / overview
- `about.html` — Company background, registration, offices and standards
- `services.html` — Roads and highways, civil/building works, structural/fabrication, and site work
- `projects.html` — Filterable project gallery with an image lightbox
- `contact.html` — India and international office details plus a project enquiry form that opens WhatsApp with a prefilled message

## Run locally

The site uses plain HTML, CSS and JavaScript. Preview it with any static server and publish it to any static host. The enquiry form opens WhatsApp at `https://wa.me/919246520788` with the visitor’s details and project message formatted for review. They choose Send in WhatsApp; no server, email service, API key or form database is needed.

1. Extract the ZIP file.
2. Serve the folder with a static server for local preview.
3. Deploy the folder to any static host.

## Before going live

- Confirm the address, phone numbers and email addresses against the latest official company records. These were taken from the supplied company profile and may have changed since it was prepared.
- Review the project gallery before publication. The company profile contains capabilities and office details but no named project records. The gallery is labeled as illustrative imagery; replace it with company-approved project photos and verified client, location, scope and completion details before presenting formal case studies.
- The supplied PDF contains no logo artwork. The site therefore uses a typographic company name wordmark rather than presenting the invented DHT badge as an official logo. Replace it with approved artwork when available and confirm the brand colours.
- The pages load Google Fonts from Google Fonts. System font fallbacks are included if that service is unavailable.

## Files

- `assets/css/style.css` — all styles and responsive breakpoints
- `assets/js/site.js` — mobile navigation, active page state, reveal effects, project filters, lightbox and WhatsApp enquiry formatting
- `assets/images/` — WebP construction and reference imagery
